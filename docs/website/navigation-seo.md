# Navigation & SEO

## Navigation

Header and footer links come from **Menus** with locations `header` and `footer`. Nested items become dropdowns.

Broken public links are usually:

- Wrong URL on a menu item  
- Unpublished page/post  
- Typo in slug  

## SEO

Per-record **meta title** and **meta description** (and Open Graph where implemented) should be filled for important pages. Fallbacks use the site name and titles when meta is empty.
