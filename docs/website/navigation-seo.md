# Navigation & SEO

## Navigation

Header and footer links come from **Menus** with locations `header` and `footer`. Nested items become dropdowns.

Social icons in the header and footer come from **Site Settings → Social links**. The Know Us mega-menu intro and globe markers are also Site Settings.

If the header menu has no items, mobile navigation uses **Site Settings → Mobile menu fallback**.

Broken public links are usually:

- Wrong URL on a menu item  
- Unpublished page/post  
- Typo in slug  

## SEO

Per-record **meta title** and **meta description** (and Open Graph where implemented) should be filled for important pages. When those are empty, the public site uses **Site Settings → SEO defaults** (site-wide fallback, plus dedicated home title/description). Search-dialog wording is **Site Settings → Search**.
