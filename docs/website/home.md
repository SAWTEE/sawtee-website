# Home page

The home page assembles **homepage sections** that are enabled in the CMS.

Typical blocks (order may vary by design):

1. **Carousel** — slides from the Home slider  
2. **Feature cards** — illustrated cards from **Features** (active rows only)  
3. **Featured publications** — publications (and sometimes blogs) tagged `featured`  
4. **In focus / policy / latest pubs / media / newsletter / webinars** — driven by categories, tags, and section toggles  

Section **headings and intros** come from **Homepage sections**. The newsletter callout can fall back to **Site Settings → Newsletter** if those fields are empty. The hidden H1 and some column labels come from **Site Settings → Home extras**.

If a block is missing on the live site:

1. Check **Homepage sections → Show** for that block  
2. Confirm there is published content in the expected category/tag (or an active Feature, for the feature cards)  
3. Wait a few minutes or clear application cache if a recent change does not appear
