# Categories, tags & themes

## Categories

Hierarchical. Types commonly include **post** and **publication**.

- Parent categories group archives.  
- Child categories refine filters and URLs.  
- Optional category image and SEO fields.

## Tags

Free-form labels (e.g. `featured`) used for home rails and cross-links. Keep names short and consistent.

## Themes

Optional thematic grouping on posts for browsing and filtering. Title + description only.
