# Posts & articles

## Posts

Posts power most chronological content: blogs, events, newsletters, webinars, SAWTEE in media, in-focus items, and more.

### Creating a post

1. **Posts → Create**  
2. Enter **title**, **category**, optional **theme**, **author**, **status**  
3. Write **content** in the editor  
4. Optional: excerpt, link (external), genre, publish date  
5. Upload **featured image** and optional PDF/file  
6. Attach **tags**  
7. Save

### Categories decide the template

The public URL looks like:

`/category/{category-slug}/{post-slug}`

Special categories (events, webinars, publications archives, etc.) use dedicated frontend templates. Pick the correct category so the right layout appears.

### Titles

Post **title** must be unique within the chosen **category**. Reusing the same title in a different category is allowed.

### Trash (soft delete)

Deleting a post from the index moves it to **Posts → Trash** (not removed immediately). From Trash you can:

- **Restore** — put the post back on the live index  
- **Delete permanently** — remove it for good (associated media is kept until permanent delete)

Bulk restore / permanent delete are available on the trash screen. Featured images and attachments stay with the post while it is only soft-deleted.

### Articles

Articles belong to a **publication**. Use them for chapters or pieces inside a volume (e.g. Trade Insight). Create from **Articles**, choose the parent publication, then add content and tags as needed.
