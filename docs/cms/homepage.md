# Homepage sections

**Homepage sections** are toggles that show or hide major home blocks without a deploy.

Examples of section names used by the frontend:

- Carousel  
- Featured Publication  
- Infocus  
- Policy Outreach  
- Latest Publications  
- Sawtee in Media  
- Newsletter  
- Webinar  
- Newsletter Callout  

Set **Show** on for sections that should appear. Order can be stored for admin organisation; visibility is what the home page reads.

### Featured publication rail

Needs:

1. Homepage section **Featured Publication** → show on  
2. Publications tagged **`featured`**  
3. Optional featured blog posts (opinion / commentary / blog with `featured` tag)
